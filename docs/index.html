SENTINEL-VF

Multi-Vendor DVR/NVR Forensic Analysis Tool

Universal Video Forensics & Evidence Integrity Framework

About The Project

SENTINEL-VF is a forensic analysis framework designed to standardize DVR/NVR evidence acquisition, verification, timeline reconstruction and forensic reporting. The system provides a unified approach for handling surveillance evidence from multiple vendors.

Problem Statement

Traditional CCTV forensic investigations face challenges:

  • Vendor-specific DVR/NVR formats
  • Missing or unreliable metadata
  • Timestamp inconsistencies
  • Difficult evidence verification
  • Lack of standardized reporting

Our Solution

SENTINEL-VF introduces three major forensic engines to recover, validate and analyse surveillance evidence.

Forensic Pipeline

Core Modules

Evidence Trust Core

Evidence acquisition, hashing and integrity verification.

Temporal Truth Engine

Timestamp reconstruction and timeline uncertainty analysis.

Evidence Knowledge Graph

Connects devices, artifacts, events and claims.

AI Review Module

Assisted analysis and evidence review support.

Report Generator

Creates structured forensic investigation reports.

Future Scope

Future improvements include:

  • Support for more DVR/NVR vendors
  • Advanced AI assisted forensic analysis
  • Automated evidence validation
  • Investigation workflow automation
