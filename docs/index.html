Universal Video Forensics & Evidence Integrity Framework

About The Project

SENTINEL-VF is a forensic analysis framework designed to standardize DVR/NVR evidence acquisition, verification, timeline reconstruction and forensic reporting.

Problem Statement

  • Vendor-specific DVR/NVR formats
  • Missing metadata
  • Timestamp inconsistencies
  • Difficult evidence verification
  • Lack of standardized reporting

Our Solution

Three forensic engines help recover, validate and analyse surveillance evidence.
